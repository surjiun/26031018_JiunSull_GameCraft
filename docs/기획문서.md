# 패링 액션 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | 패링 액션 |
| 장르 | 패링 중심의 2D 사이드뷰 액션 |
| 게임 방식 | 좌우로 이동하는 창고 통로에서 제한 시간 내 모든 적 처치 |
| 조작 방식 | 메뉴는 마우스 클릭, 플레이는 키보드 A/D 이동, J 공격, K 패링 |

---

## 2. 기획 의도와 핵심 재미

좌우에서 접근하는 적의 공격을 읽고, 패링과 반격으로 처치하는 액션 게임이다. 카타나 제로의 빠른 전투 분위기를 참고하되, 고정된 바닥에서의 좌우 이동과 전투에 집중한다. 아래 규칙은 최종 목표이며, 현재 구현 범위는 9절에서 구분한다.

적은 일반 공격에 맞아도 행동을 멈추지 않는다. 따라서 공격만 반복하기보다 적의 준비 동작을 보고 거리를 벌리거나, 패링으로 공격을 끊어 안전한 반격 기회를 만들어야 한다.

- **공격 예고에 대응:** 적의 준비 동작을 보고 회피 또는 패링을 선택한다.
- **패링 후 반격:** 근접·돌진 공격을 패링하여 적을 무력화하고 공격한다.
- **원거리 탄 반사:** 날아오는 탄을 튕겨내 적에게 피해를 준다.
- **연속 패링:** 성공 시 패링 대기 시간이 초기화되어 다음 공격에도 바로 대응할 수 있다.

---

## 3. 게임 목표

제한 시간 안에 스테이지에 정해진 모든 적을 처치하는 것이 목표다. 적은 좌우에서 등장하며, 도망만 다니면 제한 시간 때문에 클리어할 수 없다.

| 결과 | 조건 |
|---|---|
| 승리 | 제한 시간이 끝나기 전에 등장 예정인 적을 포함한 모든 적 처치 |
| 패배 | 플레이어 체력 소진 또는 모든 적을 처치하지 못한 상태에서 제한 시간 종료 |

남은 적 수에는 아직 등장하지 않은 적도 포함한다. 화면에 적이 잠시 없더라도 등장 예정인 적이 남아 있으면 게임은 계속된다.

## 4. 조작 방법

| 키 | 기능 |
|---|---|
| A / D | 좌우 이동 및 바라보는 방향 변경 |
| J | 바라보는 방향으로 근접 공격 |
| K | 바라보는 방향의 공격을 짧은 시간 동안 패링 |
| 마우스 왼쪽 클릭 | 시작 화면의 시작·종료 버튼 선택. 결과 화면의 재시작·종료 버튼은 추후 연결 |

- 이동을 멈춰도 마지막으로 바라본 방향을 유지한다.
- 공격과 패링은 버튼을 새로 누를 때 한 번 발동한다.
- 공격·패링 중에는 이동과 방향 전환을 할 수 없다. 동작이 끝나면 다시 이동할 수 있다.
- 공격과 패링은 동시에 사용하거나 도중에 서로 취소할 수 없다. 사용 가능한 상태에서 J와 K를 동시에 누르면 패링을 우선한다. 패링 쿨타임 중에는 K를 무시하고, J를 새로 누르면 공격할 수 있다.
- 공격·패링 중에 누른 다른 행동 입력은 저장하지 않는다. 행동이 끝난 뒤 새로 눌러야 한다. A/D는 누르고 있으면 이동 가능한 상태가 된 다음 다시 이동한다.
- 패링 성공 후에는 마무리 자세 중에도 K를 새로 눌러 다음 패링을 시작할 수 있다.

## 5. 게임 규칙

### 5.1 이동과 일반 공격

- 캐릭터는 고정된 바닥 위에서 좌우로 이동하며, 경기장 양 끝을 넘어갈 수 없다. 점프와 중력은 사용하지 않는다.
- 캐릭터끼리는 서로 통과할 수 있으며, 몸이 닿는 것만으로는 피해를 주지 않는다.
- 일반 공격은 패링 성공 여부와 관계없이 사용할 수 있다. 전방 공격 범위 안의 적에게 피해를 주며, 한 번의 공격은 같은 적에게 한 번만 피해를 준다.
- 다음 일반 공격은 현재 공격 동작이 끝난 뒤 J를 다시 눌러 사용할 수 있다.
- 적은 일반 공격이나 반사된 탄에 맞아도 체력만 감소하고, 진행 중인 이동·공격을 유지한다.

### 5.2 플레이어 피격

- 적의 근접 공격·돌진·탄에 맞으면 체력이 감소한다. 패링은 성공한 해당 공격의 피해만 막으며, 피격 무적 상태에서는 추가 피해를 받지 않는다.
- 피격 시 경직이나 밀려남 없이 조작과 진행 중인 동작을 유지한다.
- 피격 후 짧은 무적 시간을 부여하여 여러 공격에 의한 연속 피해를 방지한다.
- 피격은 색 변화나 깜빡임, 타격 효과로 표시한다. 피격 표현이 행동을 중단시키지는 않는다.
- 플레이어와 적 모두 체력이 0이 되면 진행 중인 행동을 중단하고 사망한다.

### 5.3 패링과 무력화

패링 동작 자체에는 피해가 없으며, 버튼을 누르고 유지하는 별도의 가드는 사용하지 않는다.

| 상황 | 처리 |
|---|---|
| 유효 시간에 정면 공격을 막음 | 해당 공격의 피해를 막고 패링 성공 |
| 근접·돌진 공격 패링 성공 | 해당 공격 중단 및 적 무력화 |
| 원거리 탄 패링 성공 | 탄의 방향과 공격 대상을 변경하여 반사 |
| 패링 성공 후 | 유효 판정 종료, 재사용 대기 시간 즉시 초기화, 마무리 자세로 전환. K를 새로 누르면 즉시 다음 패링 가능 |
| 아무 공격도 막지 못하고 유효 시간 종료 | 그 시점부터 재사용 대기 시간 발생, 마무리 자세로 전환 |
| 유효 시간 밖 또는 후방에서 공격받음 | 피격 무적 상태가 아니면 피해 발생 |

- 무력화는 일정 시간 이동과 공격을 할 수 없는 경직 상태다. 근접·돌진형은 패링 한 번에 무력화된다.
- 무력화가 끝나면 적은 다시 행동하며, 무력화될 수 있는 총횟수에는 제한이 없다.
- 성공 후 다음 패링은 K를 다시 눌러 사용한다. 재사용 대기 중에는 패링할 수 없다.
- 패링 성공 자체로 무적 시간이 생기지는 않는다. 다른 공격까지 막으려면 다시 패링해야 한다.
- 같은 공격은 한 번만 패링할 수 있다. 피격으로 진행 중인 패링 대기 시간이 초기화되지는 않는다.

### 5.4 원거리 탄

- 탄은 수평으로 이동하며, 발사한 적의 행동과 별도로 처리한다.
- 적의 탄은 플레이어에게 명중하면 피해를 주고 사라진다. 피격 무적 중에 접촉한 탄도 사라지며 피해는 주지 않는다.
- 반사된 탄은 플레이어에게 피해를 주지 않고, 적에게 명중하면 피해를 주고 사라진다.
- 스테이지 양 끝을 벗어난 탄은 제거한다. 카메라가 이동해 화면에서 잠시 보이지 않는 탄은 계속 이동한다.
- 탄을 패링해도 발사한 적이 즉시 무력화되지는 않는다.

### 5.5 적 등장과 수치 조정

- 정해진 수의 적이 경기장 좌우 끝에서 등장한다.
- 첫 적은 왼쪽에서 등장한다. 전체 적 수의 절반 미만을 처치한 초반에는 한 마리만 유지하고, 처치하면 다음 적이 직전 등장 위치의 반대쪽에서 등장한다.
- 전체 적 수의 절반 이상을 처치하면 후반으로 전환하며, 동시에 살아 있는 적이 최대 두 마리가 되도록 등장시킨다. 상한에 도달하면 추가 등장을 보류한다.
- 적의 등장 순서·간격·총수와 제한 시간은 플레이를 통해 조정한다.
- 체력·피해량·공격 간격·패링 시간·무력화 시간·피격 무적 시간도 조정한다. 일반 공격만으로 적의 공격 전에 쉽게 처치되지 않도록 설정한다.


### 5.6 플레이어 행동 구분과 처리 순서

플레이어는 현재 행동을 하나만 가진다. 위치·방향·행동·현재 프레임·행동 경과 시간·패링 쿨타임을 따로 보관한다. 피격 무적 시간과 체력은 적 전투를 연결할 때 추가한다.

| 행동 | 시작 조건 | 처리 | 종료 조건 |
|---|---|---|---|
| 대기 `Idle` | 이동 입력이 없거나 행동이 끝남 | 대기 4프레임 반복, 마지막 방향 유지 | 이동 또는 사용 가능한 공격·패링 입력 |
| 이동 `Move` | 이동 가능한 상태에서 A/D 입력 | X 좌표·방향 갱신, 이동 6프레임 반복 | 입력 해제·경계 도달 또는 공격·패링 시작 |
| 공격 `Attack` | 대기·이동 중 J를 새로 누름 | 위치·방향 고정, 공격 6프레임 한 번 재생, 유효 구간에만 명중 판정 | 0.6초 경과 후 대기 |
| 패링 `Parry` | 대기·이동 중 K를 새로 누르고 쿨타임이 0 | 위치·방향 고정, 정면 공격 수신 검사 | 성공하거나 0.2초 경과하면 패링 마무리 |
| 패링 마무리 `ParryRecovery` | 패링 성공 또는 유효 시간 종료 | 회수 자세를 0.12초 유지, 이동·공격·패링 판정 없음 | 시간 종료 후 대기. 성공했다면 새 K 입력으로 즉시 패링 가능 |
| 사망 — 추가 예정 | 체력이 0 이하 | 모든 조작·공격 판정 중지, 사망 8프레임 한 번 재생 | 마지막 자세 유지, 패배 처리 |

`Player.Update()`는 다음 순서로 처리한다. 공격·패링 중에는 이동 메서드를 호출하지 않으므로 위치와 방향이 바뀌지 않는다.

```text
패링 쿨타임 감소 — 0 아래로 내려가지 않음
    ↓
현재 행동 판단
    ├─ 공격 중 → UpdateAttack()
    ├─ 패링·패링 마무리 중 → UpdateParry()
    ├─ K를 새로 누름 + 쿨타임 0 → 패링 시작
    ├─ J를 새로 누름 → 공격 시작
    └─ 그 외 → UpdateMovement()로 A/D 이동 또는 대기 처리
    ↓
UpdateAnimation()으로 현재 행동의 표시 프레임 결정
```

- 이동은 `이동 방향 × 초당 이동 속도 × 이전 업데이트 이후 경과 시간`만큼 X를 변경한다. A는 -1, D는 +1이며 동시에 누르면 0이다.
- 현재 이동 속도는 초당 260픽셀이다. 스테이지 너비는 1920, 플레이어 셀 너비는 192이므로 X는 0~1728로 제한한다. Y는 고정하고 발바닥을 바닥 높이에 맞춘다.
- 공격 유효 시간은 시작 후 **0.2초 이상~0.4초 미만**이다. 나머지 시간에는 공격 이미지가 보여도 피해를 주지 않는다. 휘두름 소리는 유효 구간이 시작될 때 한 번만 재생한다.
- 패링 판정은 시작 후 **0.2초 미만**에만 유효하다. 실패하면 0.8초 쿨타임을 시작한다. 쿨타임은 마무리 동작 중에도 감소한다.
- 패링 시트는 **2번(앞으로 쳐냄) → 1번(몸 쪽으로 회수)** 순서로 각각 0.1초 재생한다. 마무리에는 1번을 유지하며, 이 구간에 추가 방어 판정은 없다.
- 대기·이동은 마지막 프레임 다음에 첫 프레임으로 돌아간다. 공격·패링은 반복하지 않는다. 행동이 바뀌면 프레임과 행동 시간을 초기화한다.
- 사망을 추가할 때는 위 행동 판단보다 체력 0 검사를 먼저 수행한다. 일반 피격은 체력·무적 시간만 바꾸고 현재 행동을 초기화하지 않는다.

위 시간·속도는 현재 코드의 초기값이다. 적과 실제 전투를 연결한 뒤 조정한다.

### 5.7 공격 대상과 방어 판정의 연결

좌표와 판정 사각형은 스테이지 기준으로 계산한다. 카메라 위치는 화면에 그릴 때만 빼며, 충돌 계산에는 적용하지 않는다.

**플레이어가 적을 공격하는 경우**

1. `PlayScene`이 살아 있는 적을 순회한다. 각 적은 서로 다른 번호와 몸 판정 사각형을 가진다.
2. 각 적에 대해 `Player.TryHitEnemy(적 번호, 몸 영역, 방어 여부)`를 호출한다. 적 번호는 사망한 뒤 다른 적에게 재사용하지 않는다.
3. 공격 유효 시간 밖이거나 전방 공격 영역과 몸 영역이 겹치지 않으면 `Miss`를 반환한다.
4. 겹치면 적 번호를 이번 공격의 명중 목록에 기록한다. 방어 중이면 `Blocked`, 아니면 `Hit`를 반환한다.
5. 적은 `Hit`일 때만 공격 피해량만큼 체력을 줄인다. 같은 공격에서 이미 기록된 적에게는 다시 피해를 주지 않는다. 새 J 공격을 시작할 때 명중 목록을 비운다.

현재 적 기획에는 별도 가드 행동이 없으므로 적 연결 시 방어 여부에는 우선 `false`를 전달한다. 방어 여부 인자는 함수의 판정 결과 구분용이며, 적에게 새 가드 패턴을 추가했다는 뜻은 아니다.

**적의 공격이 플레이어에게 닿는 경우**

1. 적의 공격이나 탄마다 플레이어에게 이미 처리했는지를 보관한다. 공격 유효 시간에만 겹침을 확인하며 같은 공격을 매 프레임 중복 적용하지 않는다.
2. 공격 영역이 플레이어 몸 영역과 겹치면 `Player.ReceiveAttack(공격 영역, 공격이 오는 쪽의 X 좌표)`를 호출한다. 탄은 발사자의 현재 위치 대신 탄이 날아오는 쪽을 기준으로 한다.
3. `Miss`이면 피해 없이 계속 검사한다. `Parried`이면 해당 공격을 소모하고, 근접·돌진형은 무력화하거나 탄을 반사한다. 이때 플레이어의 패링 쿨타임은 0이 되고 성공음을 한 번 재생한다.
4. `Hit`이면 피격 무적 여부를 확인한 뒤 체력을 감소시킨다. 무적 중이어도 해당 공격의 접촉은 처리한 것으로 기록한다. 탄은 사라진다.
5. 판정 함수는 결과를 반환하고, 실제 적 체력 감소·무력화·탄 제거는 해당 객체와 `PlayScene`이 처리한다. 현재는 판정 함수만 있으며, 적 연결 및 플레이어 체력·무적 처리는 추가할 부분이다.

## 6. 적 종류와 행동 흐름

| 종류 | 공격 방식 | 패링 결과 |
|---|---|---|
| 근접형 | 가까이 접근하여 전방 공격 | 공격 중단 및 무력화 |
| 돌진형 | 준비 자세 후 직선 돌진 | 돌진 중단 및 무력화 |
| 원거리형 | 일정 거리에서 수평 탄 발사 | 탄 반사 |

### 6.1 근접형

```text
플레이어에게 접근
    ↓
공격 거리 진입
    ↓
정지 후 방향 고정 및 공격 예고
    ↓
전방 근접 공격
    ├─ 패링됨 → 공격 중단 및 무력화
    ├─ 명중 → 플레이어 피격 처리
    └─ 빗나감 → 피해 없음
    ↓
무력화된 경우 회복을 기다린 뒤 재공격 대기
    ↓
접근부터 반복
```

공격 준비 이후에는 플레이어를 따라 공격 방향을 바꾸지 않는다. 플레이어는 거리를 벌려 피하거나 정면에서 패링할 수 있다.

### 6.2 돌진형

```text
플레이어에게 접근
    ↓
돌진 시작 거리 진입
    ↓
정지 후 돌진 방향 고정 및 준비 자세
    ↓
고정된 방향으로 직선 돌진
    ├─ 패링됨 → 즉시 돌진 중단 및 무력화
    ├─ 명중 → 플레이어 피격 처리 후 돌진 종료
    └─ 최대 거리 또는 경기장 끝 도달 → 돌진 종료
    ↓
무력화된 경우 회복을 기다린 뒤 재공격 대기
    ↓
접근부터 반복
```

준비 자세 이후에는 돌진 방향을 바꾸지 않으며, 한 번의 돌진으로 같은 플레이어에게 피해를 반복해서 주지 않는다.

### 6.3 원거리형

```text
플레이어에게 접근
    ↓
사격 거리 진입
    ↓
정지 후 발사 준비
    ↓
플레이어 방향으로 수평 탄 한 발 발사
    ↓
일정 시간 대기
    ↓
플레이어와의 거리 확인
    ├─ 사격 거리 안 → 발사 준비부터 반복
    └─ 사격 거리 밖 → 접근부터 반복
```

### 6.4 공통 행동 관리

적의 위치·체력·방향·피격·무력화 처리는 공통으로 관리하고, 종류에 따라 이동과 공격 방식을 구분한다.

행동트리는 다음 우선순위로 행동을 선택한다. 선택한 공격은 준비·공격·대기 상태로 진행한다.

```text
적의 행동 판단
    ├─ 체력 0 → 사망 처리 후 행동 종료
    ├─ 무력화 중 → 회복까지 이동·공격 중지
    ├─ 준비·공격·대기 중 → 진행 중인 행동 유지
    ├─ 공격 거리 안이며 재공격 가능 → 종류에 맞는 공격 시작
    └─ 그 외 → 플레이어에게 접근
```

사망이나 패링에 의한 무력화는 진행 중인 공격보다 우선한다. 일반 피격은 공격을 중단시키지 않는다.

적은 `접근 / 준비 / 공격 / 재공격 대기 / 무력화 / 사망` 상태를 구분한다. 상태를 바꿀 때 경과 시간을 0으로 만들고, 준비에서 공격으로 넘어갈 때 해당 공격의 명중 기록을 비운다. 무력화될 때는 공격 판정을 즉시 끄고, 회복 시간이 지나면 재공격 대기로 전환한다.

행동트리는 위 우선순위의 조건을 차례로 확인해 실행할 행동을 고르는 용도다. 각 행동 내부의 준비 시간·이동 거리·공격 시간은 별도 상태와 타이머로 처리한다. 공격 예고 시간·무력화 시간 등의 적 수치는 근접형 한 마리를 연결하는 단계에서 정하고 조정한다.

## 7. 게임 진행과 화면 구성

### 7.1 전체 진행 흐름

```text
프로그램 실행
    ↓
시작 화면
    ├─ 종료 버튼 클릭 → 프로그램 종료
    └─ 시작 버튼 클릭 → 체력·남은 적 수·제한 시간 초기화
                   ↓
               게임 플레이
                   ├─ 제한 시간 내 모든 적 처치 → 승리
                   └─ 체력 소진 또는 시간 초과 → 패배
                   ↓
               결과 화면
                   ├─ 재시작 버튼 클릭 → 초기화 후 재시작
                   └─ 종료 버튼 클릭 → 프로그램 종료
```

시작·재시작 시 플레이어 위치·방향·체력·행동·프레임, 공격 명중 목록, 패링 쿨타임·피격 무적 시간을 초기화한다. 기존 적과 탄을 비우고 처치 수·등장 순서·다음 등장 시간·남은 시간·카메라 위치도 처음 상태로 돌린다.

플레이 중에는 플레이어와 적·탄을 갱신하고 공격 판정을 처리한 뒤 체력과 남은 적 수를 갱신한다. 플레이어 체력이 0이거나 시간이 끝났으면 패배로 전환하고, 그 외에 남은 적이 0이면 승리로 전환한다. 같은 업데이트에 조건이 겹치면 패배를 우선한다. 결과 화면에서는 전투와 제한 시간 갱신을 멈춘다.

### 7.2 화면 구성

| 화면 | 주요 요소 | 기능 |
|---|---|---|
| 시작 | 배경, 게임명, 시작·종료 버튼 | 마우스로 게임 시작 또는 종료 |
| 플레이 | 상단 왼쪽 체력, 상단 중앙 남은 시간, 상단 오른쪽 남은 적 수 | 진행 상황 확인 |
| 플레이 | 하단 고정 바닥, 플레이어와 적, 탄 | 좌우 이동 및 전투 |
| 플레이 | 패링 재사용 가능 여부 표시 | 패링 가능 시점 확인 |
| 결과 | 승리·패배 문구, 재시작·종료 버튼 | 결과 확인 및 재도전 |

공격 준비 동작으로 위험을 예고하고, 패링 성공 시 효과와 효과음을 재생한다. 이동·공격·피격·무력화 상태가 구분되도록 표현한다.

## 8. 클래스 역할과 화면 좌표

| 클래스 | 맡는 역할 |
|---|---|
| `GameMain` | 현재 화면을 보관하고 해당 화면의 갱신·그리기를 호출한다. 공통 BGM을 반복 재생하고 종료 시 자원을 정리한다. 결과 화면 전환은 추후 추가한다. |
| `MainMenu` | 메뉴 배경·로고·버튼을 그린다. 버튼 안에서 누르고 같은 버튼 안에서 놓았을 때 시작 또는 종료 결과를 반환한다. |
| `PlayScene` | 배경과 플레이어를 관리한다. 플레이어 갱신 후 카메라를 계산하고 배경·캐릭터 순서로 그린다. 추후 적·탄 목록, 전투 판정 호출, 등장·제한 시간·승패 처리를 추가한다. |
| `Player` | 입력에 따라 행동을 선택하고 이동·공격·패링의 하위 메서드를 호출한다. 자신의 위치·방향·애니메이션·공격 명중 목록·패링 쿨타임을 관리한다. |
| 적·탄 — 추가 예정 | 적은 공통 위치·체력·종류·행동 상태를 보관한다. 탄은 위치·이동 방향·공격 대상·소모 여부를 따로 보관한다. |

- 게임 화면은 960×540, 플레이 배경은 1920×540이다. 스테이지의 높이는 고정하고 좌우로 이동한다.
- 캐릭터와 적·탄은 스테이지 좌표를 가진다. 화면에 그리는 X 좌표는 `스테이지 X - 카메라 X`이다.
- 카메라 X는 `플레이어 중심 X - 화면 너비의 절반`으로 계산하고 0~960으로 제한한다. 왼쪽과 오른쪽 끝에서는 카메라가 멈추고, 중간에서는 플레이어가 화면 중앙에 오도록 따라간다.
- 메뉴와 체력·시간 같은 화면 UI는 화면 좌표를 사용하며 카메라 이동의 영향을 받지 않는다.
- 버튼은 기본·선택·눌림 이미지를 공유한다. 마우스가 올라가면 선택, 버튼 위에서 누르는 동안 눌림 상태를 표시한다. 현재 메뉴 버튼 글자는 생략한 1차 배치다.
- BGM은 메뉴와 플레이에서 이어 재생한다. 클릭음은 버튼을 누를 때, 검 휘두름은 공격 유효 구간 시작 때, 패링 동작음은 K로 동작을 시작할 때, 금속 충돌음은 실제 패링 성공 때만 재생한다.

## 9. 3차 제출 시점의 구현 범위

| 구분 | 현재 상태 |
|---|---|
| 메뉴·플레이 화면 | 배경·로고·버튼 표시, 마우스 시작·종료, 플레이 화면 전환 구현 |
| 이동·카메라 | 플레이어 표시, A/D 이동·방향 전환, 경계 제한, 좌우 카메라 이동 구현 |
| 플레이어 행동 | 대기·이동 반복, 공격 단발, 패링 2→1 재생, 마무리 자세와 행동 중 이동 제한 구현 |
| 전투 판정 기반 | 공격 범위·같은 적 중복 명중 방지·방어 여부 반환, 정면 패링 성공·실패와 쿨타임 함수 구현 |
| 사운드·리소스 | BGM·클릭·휘두름·패링 동작·성공음 연결, 리소스 폴더·목록·음원 출처 정리 |
| 추가할 부분 | 실제 적과 탄, 체력·피격 무적·사망 코드 연결, 전투 HUD, 적 등장·제한 시간·승패·재시작 |

현재 L키는 패링 성공을 확인하는 임시 입력이다. K를 누른 뒤 유효 시간 안에 L을 누르면 정면 공격을 받은 것으로 처리해 실제 판정 함수를 호출한다. 적 공격을 연결한 뒤 이 입력 블록은 삭제한다. 적이 아직 없으므로 L키 테스트가 실제 전투 구현 완료를 의미하지는 않는다.

근접형 적을 기준으로 기본 전투와 게임 시작·승패·재시작 처리를 먼저 완성한 후, 돌진형과 원거리형 및 탄 반사를 추가한다.
